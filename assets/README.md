Place your real assets in this directory before build:

- themes/Aerobird-for-Xfce/   -> Xfce window / GTK theme
- wallpapers/techos-default.jpg -> default desktop background
- icons/tech-logo.svg         -> circular TechOS menu icon
- techos-panel.tar.bz2        -> /etc/xdg/xfce4 pre-configured panel profile

If missing, the build script falls back to sensible defaults.
